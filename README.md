## English

### Portside — an open-world browser game GPT 6 Astra kept improving (v1.1, v2, v3)

The video series where **GPT 6 Astra** kept improving its game Portside: v1.1 adds cars, weapons, a 2× map and police; v2 adds first-person view, car interiors, a 5-star wanted level and a helicopter; v3 adds a day/night cycle, textures and a fixed camera. The first version lives in [GPT-6-Astra-AI-Games](https://github.com/Cryptopiy/GPT-6-Astra-AI-Games).
