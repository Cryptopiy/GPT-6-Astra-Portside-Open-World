# Portside — маленький открытый мир

> **Как запустить готовую сборку / How to run the ready-made build:** см. / see [HOW_TO_PLAY.md](../../HOW_TO_PLAY.md) в корне репозитория / in the repository root. Если ниже упоминаются другие файлы запуска — их в этом репозитории нет / if other launch files are mentioned below, they are not part of this repository.

Самостоятельная браузерная 3D-игра: прогулки и поездки по городу, оружие, полиция и погоня. Игра работает локально и не требует аккаунта, API-ключа или подключения к внешнему сервису.

## Быстрый запуск в Windows

Требуется Node.js 22.12 или новее и браузер с поддержкой WebGL 2.

1. Полностью распакуйте архив.
2. Запустите `START.cmd`.
3. Откройте <http://127.0.0.1:5181/> в браузере.

При первом запуске зависимости будут загружены автоматически. Для остановки сервера закройте окно командной строки или нажмите `Ctrl+C`.

Ручной запуск из PowerShell:

```powershell
npm.cmd ci
npm.cmd run dev -- --port 5181 --strictPort
```

## Управление

- `WASD` или стрелки — движение; в машине газ, тормоз и руль.
- Мышь — обзор; `Shift` — бег; `Space` — тормоз.
- `E` — взаимодействие, вход или выход из машины.
- `1`, `2`, `3` — нож, пистолет и автомат.
- ЛКМ — атака; ПКМ — прицеливание; `R` — перезарядка.
- `C` — расстояние камеры; `N` — большая карта; `H` — справка; `M` — звук.
- `Esc` — пауза; `P` — продолжить; `T` — повторить миссию.

## Проверка и сборка

```powershell
npm.cmd test
npm.cmd run build
```

Готовая production-версия создаётся в папке `dist`. Её нужно открывать через HTTP-сервер, например:

```powershell
python -m http.server 5181 --bind 127.0.0.1 --directory dist
```

После этого откройте <http://127.0.0.1:5181/>. Прямой запуск `dist/index.html` двойным щелчком не поддерживается.

## Состав проекта

- `src` — исходный код игры.
- `tests` — автоматические тесты.
- `public` — статические ресурсы.
- `dist` — готовая собранная версия.
