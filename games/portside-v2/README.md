# GTA v2 — Portside

> **Как запустить готовую сборку / How to run the ready-made build:** см. / see [HOW_TO_PLAY.md](../../HOW_TO_PLAY.md) в корне репозитория / in the repository root. Если ниже упоминаются другие файлы запуска — их в этом репозитории нет / if other launch files are mentioned below, they are not part of this repository.

Самостоятельный 3D-город с ходьбой, вождением, миссией доставки, оружием и полицейскими погонями. Комплект содержит актуальные исходники и готовую игру.

**Распакуйте весь архив и дважды нажмите START для своей системы:**

- **Windows:** `START.cmd`.
- **Mac:** `START.command`.

Браузер откроется автоматически — нажмите **Play**. Окно запуска оставьте открытым во время игры. Устанавливать Node.js, npm или зависимости и вводить команды не требуется: всё необходимое уже включено. Игра работает без интернета, аккаунтов и API-ключей.

Поддерживаются Windows 10/11 **64 бит** (Intel/AMD и ARM64), а также macOS **11 и новее** (Intel и Apple Silicon). Нужен браузер с WebGL 2, клавиатура и мышь. Если macOS блокирует первый запуск, следуйте разделу Mac в [инструкции](ЗАПУСК.md).

В комплект включены вид от первого лица и салоны машин, обновлённые модели людей, пять звёзд розыска с бронемашинами и вертолётом, а также анимация вытаскивания водителя и посадки.

[Подробный запуск, управление и сборка из исходников](ЗАПУСК.md).

Версия игры: **2.0.0**, комплект с автономным запуском для Windows и Mac от **11 сентября 2026 года**. Название вкладки: **GTA v2 — Portside**.

Лицензии сторонних компонентов: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) и папка `LICENSES`.
